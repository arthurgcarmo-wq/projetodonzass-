# projetodonzass-

Grupo: Enzo adan, Caio Vinicius, Maria clara, Arthur Gabriel

O site é uma plataforma criada para ajudar pessoas que estão planejando uma mudança de emprego, cidade ou estado. A ferramenta permite que o usuário informe sua situação atual e seu possível novo destino para calcular e comparar os principais custos envolvidos na mudança.

A plataforma pode considerar despesas como transporte, aluguel, alimentação, deslocamento, mudança de móveis e outros gastos iniciais. Com essas informações, o usuário consegue ter uma estimativa do custo total da mudança e avaliar se a nova oportunidade de emprego realmente vale a pena financeiramente.

O objetivo é facilitar a tomada de decisão, oferecendo uma visão clara dos gastos antes de a pessoa aceitar uma proposta de trabalho ou se mudar para outra região. Dessa forma, o site funciona como um planejador financeiro para quem está diante de uma mudança profissional e de vida.
